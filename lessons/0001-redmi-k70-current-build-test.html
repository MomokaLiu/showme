路线 A：立即用手机 Chrome 测试

这是最快路线，不需要 JDK 或 Android Studio，适合先验收界面和主要业务逻辑。

  1. 让红米 K70 和电脑连接同一个 Wi‑Fi。
  2. 在电脑 PowerShell 运行：
cd D:\vibe_projects\showme
npm run dev:android
  1. 若 Windows 防火墙弹窗，勾选“专用网络”并允许 Node.js。
  2. 在红米 K70 的 Chrome 打开 http://192.168.199.155:5173。
  3. 若电脑重新联网后地址失效，运行 npm run android:url，改用与手机同一 Wi‑Fi 网段的地址。
  4. 测试结束后回到 PowerShell，按 Ctrl+C 停止服务。
WebDAV 差异：Chrome 路线受浏览器 CORS 限制；如果服务器没有允许跨域，WebDAV 连接会失败。APK 路线使用原生 Capacitor HTTP，更适合验证 WebDAV。

路线 B：安装真正的 debug APK

1. 给电脑安装工具链

  1. 从 Android Studio 官方页面下载安装。
  2. 首次启动采用 Standard 安装，确保 Android SDK、Platform Tools 和 Build Tools 被安装。
  3. 重新打开 PowerShell，临时配置本次终端：
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:Path = "$env:JAVA_HOME\bin;$env:ANDROID_HOME\platform-tools;$env:Path"

java -version
adb version
cd D:\vibe_projects\showme
npm run android:doctor

三项都通过后，生成 APK：

npm run android:apk

产物位置：

D:\vibe_projects\showme\android\app\build\outputs\apk\debug\app-debug.apk

2. 在红米 K70 开启调试

  1. 设置 → 我的设备/关于手机 → 详细信息与规格。
  2. 连续点击“OS 版本”或“MIUI 版本”约 7 次，直到提示已进入开发者模式。
  3. 设置 → 更多设置 → 开发者选项 → 开启“USB 调试”。
  4. 用支持数据传输的 USB 线连接电脑，USB 用途选择“文件传输”。
  5. 手机弹出电脑 RSA 指纹时，只在可信电脑上选择“始终允许”，然后确认。

以上路径来自 小米开发者选项说明与 USB 调试说明。

3. 识别并安装

adb devices -l
adb -d install -r "D:\vibe_projects\showme\android\app\build\outputs\apk\debug\app-debug.apk"
  • 看到 device：连接正常。
  • 看到 unauthorized：解锁手机并确认 RSA 指纹弹窗。
  • 列表为空：换数据线/USB 口，确认 USB 调试和“文件传输”。
-r 会覆盖安装并保留现有数据。若提示签名不一致，卸载旧应用会清除本机数据；先通过 WebDAV 上传备份。

红米 K70 验收清单

  • 冷启动应用，首页、库存、临期、清单、统计均可进入。
  • 点击“添加”，填写名称和总价，保存后出现详情页。
  • 选择一张手机相册图片，确认预览、保存、库存缩略图和详情大图。
  • 创建“无期限”物品，确认实际日均成本按购入日至今天计算。
  • 结束应用进程并重新打开，确认库存与图片仍存在。
  • 设置 → WebDAV：测试连接、立即同步，确认服务器出现 buwangwu-data.json。
  • 新增一条数据后再次同步，确认显示“已上传”或“数据一致”。
  • 断网启动一次，确认本地库存仍可查看。
  • 返回键、锁屏恢复、深色系统主题和大字体下检查布局。

出问题时抓日志

adb logcat -c

# 在手机上复现问题后运行：
$appProcessId = (adb shell pidof com.buwangwu.app).Trim()
adb logcat --pid=$appProcessId

按 Ctrl+C 停止日志，把包含错误发生前后约 30 秒的内容发给我。

快速排错

手机打不开 192.168.199.155 确认同一 Wi‑Fi、电脑网络为“专用”、Windows 防火墙允许 Node.js。
ADB 找不到手机 换可传数据的线，选择文件传输，重启 ADB：adb kill-server 后 adb start-server。
APK 安装失败 先看完整错误；签名冲突时先 WebDAV 备份，再卸载旧包重装。
WebDAV 只在 Chrome 失败 多半是 CORS；优先用 APK 验证，或给服务器配置跨域响应头。
